# 长连接监听：实现与验证边界

更新日期：2026-11-11。v0.7.0 已支持可选的 Web 端长连接，升级默认仍为轮询。已通过离线协议、本机真实 WebSocket 服务及预览链路测试，没有连接真实 B 站直播间验证。

## 已核对的路径

1. **Web 端 WebSocket**：本插件已按 Web 端路径实现当前扫码账号复用，并通过离线和本机服务验证认证与重连；真实 B 站环境的可用性尚未验证。缺失或打码的 UID 不作为已知身份处理，不写入记忆。
2. **直播开放平台**：同项目的开放平台示例还需要开发者密钥、项目 ID 和主播身份码，不能直接用现有扫码状态替代这些条件。若走这条路径，需要单独的用户配置与主播授权，不作为当前插件的默认安装要求。

参考原始实现：[blivedm 项目说明](https://github.com/xfgryujk/blivedm)、[Web 客户端](https://github.com/xfgryujk/blivedm/blob/dev/blivedm/clients/web.py)、[消息协议](https://github.com/xfgryujk/blivedm/blob/dev/blivedm/clients/ws_base.py)。没有安装同名 PyPI 包；采用本插件自己的有界解码器和接收监督器，协议及 WBI 参考的 MIT 许可保留在第三方说明中。新增 Brotli>=1.2,<2 用于有界解压。

## 当前实现

- 将接收来源与现有 LiveSession 的唤醒、模型、预览和发送策略分开。长连接只产生经过校验的 RoomEvent，不承担发送或登录持久化。
- 提供显式可选模式，保留轮询入口。临时连接凭证拒绝会回退并重新获取；登录接口确认账号失效则进入待登录。
- 认证期限 10 秒；二进制心跳间隔 30 秒，75 秒没有心跳确认即断开。单包/接收缓存上限 1MiB，累计解压 4MiB，嵌套 3 层、每次最多 1000 包。断线重试 60–300 秒，停止房间时取消连接与接收任务。
- 认证前继续轮询，认证后只交付 WebSocket。来源切换时丢弃在途旧轮询，回退首批只建起点，按事件键及跨来源 UID/内容/服务端秒进行有界去重；缺失时间不猜测，缺失 UID 不进入对话和记忆。切换空档可能丢消息，不承诺完整回放或严格恰好一次。
- UI 显示实际来源、连接状态、回退原因、重试时间和心跳；恢复失败继续保留监听意图。只连接批准的 B 站 TLS 聊天主机及 443 端口，握手层拒绝重定向。临时令牌和设备标识只在内存使用。

## 切换默认接收器前的验收

- 已完成离线及本机服务测试：认证响应、普通/压缩消息、异常长度、截断包、重复包、未知 UID、停止取消、断线重连、重定向拒绝，以及只预览不发送、不写入长期记忆。旧 aiohttp 3.9 和当前版本均有离线兼容验证。
- 用户提供的授权环境中，以只预览模式验证真实认证、多房间收取、账号刷新、断网恢复、房间切换和重启恢复。
- 对比相同房间的事件数量、延迟、漏消息与重复情况；统计只能陈述实际观测，不能由模拟测试推断真实可用性。
- 通过上述验证后再评估默认替换。现有用户取消的真实直播测试不自动恢复，也不为验证接收器发送测试弹幕。
